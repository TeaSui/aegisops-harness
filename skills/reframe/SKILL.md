---
name: reframe
description: Use when the user states a consequential plan, decision or belief and asks for an opinion, a challenge, a fresh perspective or what they are missing, or is about to commit to something expensive to undo on an untested assumption. Gives the strongest case against, the load-bearing assumption, a different framing and the cheapest check that settles it. Skip when the user only wants the task carried out.
---

Target: $ARGUMENTS (default: the user's current position, restated in one sentence first)

1. **Strongest case against**, as a right opponent would argue it, from this situation's specifics; no generic pros/cons.
2. **Load-bearing assumption** that makes the view wrong if false, and what is actually known about it.
3. **Different frame:** another goal, fixed constraint, time horizon, or not solving it, that makes a different solution obvious.
4. **Cheapest check** that separates the views; run it if read-only and in scope.
5. **Verdict** and confidence. If the original view survives, say so; never manufacture disagreement or split the difference.
